## Why

外出或出國時，需要在手機快速查看不同信用卡的加碼消費額度，避免額度用完後仍持續使用同一張卡。以自行設定的回饋上限與加碼百分比換算可刷上限，記錄消費後直接呈現剩餘可刷金額。

## What Changes

- 建立 Vue 手機優先純前端應用，首頁顯示所有卡片與各活動的本期可刷上限、剩餘可刷金額及期別。
- 支援多卡、多加碼活動；每筆消費最多選一個活動，也可不選，不計算或顯示已用及剩餘回饋金。
- 可刷上限為回饋上限除以加碼百分比後無條件捨去至整數台幣；以當期消費加總扣減，最低顯示零，額度用完提醒下一筆換卡。
- 每張卡可設定日曆月或自訂結帳日；依消費日期歸期，允許手動調整，保留歷史紀錄。
- 提供新增、修改與刪除已發生的台幣消費，儲存成功後同步更新首頁及內頁。
- 使用 IndexedDB 本機保存，提供 JSON 匯出與匯入；支援 PWA 安裝與首次成功快取後的離線查看、記帳。
- 使用 impeccable 指引設計 RWD 簡約介面，以大字剩餘額度、明確操作、淺色底與單一強調色呈現。

## Capabilities

### New Capabilities

- `bonus-tracking`: 卡片與加碼活動設定、帳單期別、消費維護、剩餘可刷金額及手機優先操作。
- `local-data-portability`: 本機持久化、離線 PWA、資料備份與驗證後匯入。

### Modified Capabilities

無。現有正式規格目錄沒有能力規格。

## Impact

- 預計新增 package.json、index.html、vite.config.ts、src/、public/、tests/，實作 Vue、TypeScript 與 Vite 應用；確切套件版本於實作時查驗相容性並鎖定。
- 預計使用 Vue Router、IndexedDB 存取工具與 Vite PWA 整合，測試使用 Vitest 及瀏覽器驗證工具。
- 僅使用靜態 HTTPS 主機，無 C# Web API、伺服器資料庫、登入、跨裝置同步或銀行串接。
- 此提案只建立 Spectra 文件；不修改既有 .codex/ 使用者檔案、不安裝依賴、不建立應用程式碼、不部署。
