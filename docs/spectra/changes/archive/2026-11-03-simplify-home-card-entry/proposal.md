## Summary

精簡首頁文字並依列表狀態提供唯一的新增卡片入口，變更類型為 UI Refactor。

## Motivation

首頁目前同時顯示兩個導向相同新增表單的按鈕，容易讓使用者誤以為功能不同。標題下方與使用中空白狀態的宣傳說明增加閱讀負擔。

## Proposed Solution

- 首頁標題由「我的卡片」改為「活動加碼追蹤」。
- 移除「出發前看一眼，讓每筆消費都在加碼範圍內。」。
- 使用中列表空白時，移除「把你的第一張卡加進來」及「設定回饋上限與加碼百分比，剩下的額度交給這裡記。」；保留錢包圖示與中間新增入口，縮減空白區塊留白。
- 使用中列表空白時隱藏上方新增入口；有使用中卡片時只顯示上方入口。
- 查看已封存列表時，一律保留上方新增入口；列表空白時保留原封存提示，不提供中間新增入口。
- 所有新增入口統一標示「新增卡片」，皆導向 /cards/new。

## Impact

- Affected specs: bonus-tracking（新增首頁精簡呈現與唯一新增入口要求）
- Affected code:
  - Modified: src/views/Home.vue、src/style.css（僅首頁專用樣式，如有需要）
  - New: tests/e2e/home-card-entry.spec.ts（實作階段新增行為驗證）
  - Removed: 無
- 不新增依賴，不改變資料結構、計算、卡片建立表單或其他頁面返回連結文案。
